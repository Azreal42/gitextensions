# ADR 0088 — Navigation parent/enfant réversible

Statut : accepté sur les périmètres ci-dessous.

Reprendre les deux piles ParentChildNavigationHistory Windows, indépendantes du retour Alt+Gauche/Droite. Depuis le deuxième parent d’un merge, visiter son enfant puis revenir au parent doit retrouver ce même parent. Premier/dernier parent suivent toujours l’ordre natif fourni, même lorsqu’un retour est mémorisé. Toute autre sélection et tout remplacement du graphe invalident ces parcours. Navigate suit aussi la dernière ligne cliquée, même désélectionnée, comme LatestSelectedRevision Windows ; la recherche rapide garde sa propre récence des lignes encore sélectionnées. Pour les sélections réelles testées, F5 conserve ces ancres et la ligne de clavier sans changer la multisélection. Deux cas ordinaires supplémentaires conservent aussi la destination WorkingTree ou Index depuis le vrai éditeur du panneau Changes lors de F5 : sélection réelle retenue, texte et identité de document, focus de saisie et premier Parent/Child sans clic correcteur. Le retour Index→HEAD restaure le panneau de révision précédent. Ces preuves sont Git/headless, pas un audit natif de F5.

Les voisins appartiennent au graphe chargé : parents éventuellement réécrits par le filtre Git, enfants dans l’ordre d’insertion des arêtes Windows, avec la restriction FirstParent. Une cible hors grille produit l’erreur originale traduite ; aucun filtre élargi, rechargement d’historique, checkout ou nouveau picker. Les liens explicites Parents/Children restent dans CommitInfo.

Working directory et Index sont des destinations typées, reliées à HEAD s’il existe. Aucun faux commit ou identifiant artificiel ne part vers Git. Réutiliser les routes de sélection/panneaux existantes ; Ctrl+P/N depuis le diff garde le clavier dans la liste stable pendant la lecture, puis rend les flèches à la feuille sélectionnée lors de sa publication, seulement si aucun autre contrôle n’a pris le focus. Les cibles invisibles réutilisent la vraie boîte traduite, activée avant la première touche.

Repères : MainWindow.ParentChildNavigation, Controls/ParentChildNavigationHistory, CommitGraphLayout.Children ; commandes communes Navigate et contexte. Browse reste N2 ; audits natifs étendus et familles globales ouverts.
