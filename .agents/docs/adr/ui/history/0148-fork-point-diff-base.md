# ADR 0148 · Prochain point de branchement comme base de diff

Statut : accepté. Validation L25 conservée ; complément L26 vérifié en Git/headless, preuves et limites dans le TODO.

Ctrl+K emploie les premiers parents déjà chargés et avance au moins une fois. Il s’arrête sur une branche locale/distante ou un nombre d’enfants différent de un, comme RevisionGridControl Windows. Une étiquette distante masquée reste une vraie référence ; un tag seul ne constitue pas cet arrêt. Aucune recherche Git supplémentaire ne remplace une ligne filtrée ou absente.

Les côtés réels suivent l’ordre SelectedRows récent d’abord de WinForms 10 (DataGridViewIntLinkedList.Add). Pour n côtés, le fork est sélectionné puis les premiers max(1,n−1) anciens côtés sont rebasculés dans l’ordre Windows : collisions et dernier survivant sont conservés, avec caret distinct du primaire, éventuellement désélectionné. La sélection finale et les lecteurs de diff restent atomiques ; l’adaptation Back/Forward C7 est maintenue, sans revendiquer les pushes des singletons intermédiaires WinForms. Index/working tree gardent leurs types et le raccourci reste configurable ; aucune UI de multisélection artificielle 3+ n’est ajoutée.
