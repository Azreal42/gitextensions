# ADR 0129 — Régler les parcours locaux existants

Le lot initial AdvancedSettingsPage reprend six champs utiles de la page Windows : toujours afficher Checkout, réutiliser son action locale, forcer avec lease Commit & Push lors d’Amend, normaliser les noms et leur symbole, et afficher les options avancées. Les trois premiers ajoutent une commande de réglage à des consommateurs déjà présents ; AlwaysAdvanced était alors limité à Remotes ; le raccord commun Push/Merge/Remotes/menu est prolongé par [ADR0135](0135-shared-advanced-options.md), avec qualification distincte. Le symbole propose `_`, `-` et `(none)` — valeur vide ; un littéral hérité inconnu reste visible sans réécriture implicite.

AdvancedSettingsSession écrit uniquement les intentions modifiées dans les trois profils existants. Les conflits observés arrêtent la sauvegarde ; les reçus par fichier permettent de conserver les publications acquises et de réessayer le reste. Cancel abandonne le brouillon suivant, sans transaction globale. Le Save typé de PreferencesStore conserve seulement les clés étrangères de premier niveau valides ; il ne devient pas un writer CAS pour tous ses champs.

Les deux options Updates/RC et leur consommateur hebdomadaire complètent cette page dans [ADR0133](../../distribution/updates/0133-weekly-update-admission.md). Le masquage global DontShowHelpImages est ajouté par [ADR0134](0134-global-command-help-visibility.md), avec preuves distinctes. Console reste hors périmètre ; SSH est distinct.
