# 0135 — Ouvrir les options avancées comme Windows

Statut : implémenté ; [ciblé et natif source borné qualifiés](../../../todo.md#options-avancées-et-menu-de-références--périmètre-ciblé). Suites complètes ac59, paquet isolé et inventaire qualifiés séparément dans ce même périmètre ; limites conservées.

Le réglage Windows AlwaysShowAdvancedOptions reste false par défaut. Push, Merge et Remotes capturent le choix à chaque nouvelle fenêtre ; le menu de références le lit à chaque ouverture. Leurs états locaux restent indépendants : Show options de Push partage une seule fonction d’ouverture, Merge initialise sa case avant OptionsChanged mais reste repliable, Remotes conserve son override showAdvanced court-circuité. Aucun état d’expansion durable, option Git cochée ou opération automatique n’est ajouté. Rebase normal affiche déjà ses options comme OnShown Windows et conserve ce comportement avec false ou true.

Une lecture cosmétique illisible reprend false sans réparer ni mettre en cache le profil. Advanced garde sa barrière d’édition ; SaveAll traite explicitement InvalidDataException comme les autres erreurs attendues, montre le diagnostic et garde le brouillon ouvert après Apply ou OK. DontShowHelpImages et les choix Show/Hide locaux restent distincts. Le minimum Merge suit l’aide dépliée ; les éditeurs Push gardent 24 px avec padding compact transmis au vrai TextBox, contrôlé dans sa viewport et non par la seule boîte externe.

Sur un badge, le menu est ciblé par défaut ; Maj ou le global donnent le menu complet, Ctrl prioritaire rétablit le ciblé. Les deux formes filtrent les commandes nommées à la référence cliquée ; Other actions garde les actions secondaires. Le nom complet et RevisionHash distinguent branche/tag homonymes et tag annoté de son objet tag ; les références symboliques sont exclues. Hors badge et au clavier, le menu complet n’hérite d’aucune ancienne cible. Maj+F10 emprunte ContextRequested du contrôle focalisé sous X11 aussi, après relâchement non traité et seulement si le focus est resté identique ; les commandes configurées et le traitement natif restent prioritaires, sans double ouverture. Les scripts précèdent CI/PR dans le menu complet ; les séparateurs d’Other actions suivent le même classement Windows que leurs commandes. Push branche ouvre le dialogue partagé avec initialBranch et son remote configuré, sans remplacer le vrai checkout ; Merge/Rebase conservent le nom complet. Le contexte fermé est effacé, avec capture d’invocation Rebase séparée et gardée contre changement de dépôt/commit pendant refresh. Le retour ordinaire rend le focus à la grille ; Select in left panel prend explicitement le focus de l’arbre, sans appliquer de filtre ni reconstruire les commits.

Repères : Controls/AdvancedOptionsVisibility ; constructeurs PushDialog/MergeBranchDialog/RemotesDialog ; DesktopSettingsDialog.SaveAllAsync ; MainWindow.FocusedRevisionMenu/RevisionMenu/Rebase/Scripts/Shortcuts. AdvancedOptionsVisibilityTests et FocusedRevisionMenuTests exercent les vrais consommateurs, profils et cibles ; les suites existantes restent nécessaires.

Ce complément ne certifie pas tout Advanced ni les menus historiques. Les badges Linux restent distincts du regroupement NestledVirtualRef Windows ; actions artificielles/stash spécifiques, Advanced/Bisect complet et variantes natives restent ouverts. Niveaux et treize familles inchangés ; preuves source, ciblé, full, natif et paquet séparées dans TODO.
